# HelioCore AI — Mobile

Мобільний IoT-дашборд на **React Native (Expo)**, що відтворює веб-платформу HelioCore AI / HG Gateway. Додаток підключається до того самого backend (`server.js`, Express + PostgreSQL) і показує телеметрію пристроїв у реальному часі. Його можна встановити на Android/iOS як справжній застосунок.

## Можливості

- **Дашборд** — картки всіх пристроїв з останніми показниками (температура, вологість, освітленість, напруга, ємність, заряд) та індикатором заряду батареї.
- **Графік історії** — інтерактивний лінійний графік (SVG) для обраного пристрою з перемиканням метрик.
- **Автооновлення** — дані оновлюються кожні 5 секунд + pull-to-refresh.
- **Генератор телеметрії** — запуск/зупинка вбудованого генератора на сервері, перегляд статусу, останнього пакета, керування інтервалом.
- **Керування** — створення моделей пристроїв (JSON-schema), додавання пристроїв, прив'язка до моделі, демо-набір одним кліком.
- **Налаштування** — вказання URL сервера та API-ключа, перевірка з'єднання. Зберігається локально на пристрої.
- **Неоновий «кібер»-дизайн** — той самий темний стиль з cyan/green акцентами, що й у вебі.

## Швидкий старт

> Потрібен встановлений [Node.js](https://nodejs.org) (LTS) і телефон з застосунком **Expo Go** (App Store / Google Play) або емулятор.

```bash
# 1. Перейти в папку додатку
cd app

# 2. Встановити залежності
npm install

# 3. Запустити dev-сервер Expo
npm start
```

Після запуску:
- **На телефоні:** відскануйте QR-код у застосунку Expo Go.
- **Android-емулятор:** натисніть `a`.
- **iOS-симулятор (macOS):** натисніть `i`.
- **У браузері:** натисніть `w`.

> ⚠️ Спершу має бути запущений backend (`server.js`) — див. нижче.

## Підключення до сервера

Додаток працює з вашим `server.js` (Express + PostgreSQL у корені проєкту).

1. Запустіть backend у корені проєкту:
   ```bash
   npm install
   npm start          # сервер на http://localhost:3000
   ```
2. У додатку відкрийте вкладку **Налаштування** і вкажіть **URL сервера**:

   | Де запущено додаток | URL сервера |
   |---------------------|-------------|
   | Android-емулятор | `http://10.0.2.2:3000` |
   | iOS-симулятор | `http://localhost:3000` |
   | Реальний телефон (Expo Go) | `http://<IP-вашого-ПК>:3000` (напр. `http://192.168.0.10:3000`) |

   > IP комп'ютера в локальній мережі: `ipconfig` (Windows) або `ifconfig` / `ip addr` (macOS/Linux). Телефон і ПК мають бути в одній Wi-Fi мережі.

3. **API-ключ** (`x-api-key`) потрібен лише для надсилання даних (`POST /api/data`). Для перегляду дашборду він не обов'язковий.
4. Натисніть **Перевірити** — додаток зробить тестовий запит і покаже результат.

## Збірка інсталяційного файлу

Щоб отримати справжній файл для встановлення на пристрій, використовуйте **EAS Build** (хмарна збірка Expo).

```bash
# Встановити EAS CLI (один раз)
npm install -g eas-cli

# Увійти в обліковий запис Expo
eas login

# Android: зібрати APK (профіль preview з eas.json)
npm run build:android
#  або: eas build -p android --profile preview

# iOS (потрібен Apple Developer акаунт)
npm run build:ios
```

Після збірки EAS дасть посилання на завантаження `.apk` (Android) — його можна одразу встановити на телефон. Для iOS збірка `.ipa` потребує Apple Developer акаунта.

> **Локальна збірка без EAS** також можлива через `npx expo prebuild` + Android Studio / Xcode, але EAS — найпростіший шлях.

## API, що використовується

Усі ендпоінти — дзеркало `server.js`:

| Метод | Шлях | Призначення |
|-------|------|-------------|
| `GET` | `/api/devices/latest` | Останні дані по кожному пристрою (дашборд) |
| `GET` | `/api/devices/:id/history?limit=50` | Історія пристрою (графік) |
| `GET` | `/api/devices` | Список пристроїв з моделлю |
| `GET` | `/api/models` | Список моделей |
| `POST` | `/api/models` | Створення/оновлення моделі |
| `POST` | `/api/devices` | Створення/оновлення пристрою |
| `POST` | `/api/seed` | Демо-набір (1 модель + 3 пристрої) |
| `GET` | `/api/generator/status` | Статус генератора |
| `POST` | `/api/generator/start` | Запуск генератора |
| `POST` | `/api/generator/stop` | Зупинка генератора |

## Часті питання

**Дашборд показує «Помилка з'єднання».**
Перевірте URL сервера в Налаштуваннях, переконайтесь, що backend запущено і телефон у тій самій мережі, що й ПК.

**На реальному телефоні не працює `localhost`.**
`localhost` на телефоні вказує на сам телефон. Використовуйте IP вашого ПК у локальній мережі.

**Немає пристроїв.**
Відкрийте вкладку **Генератор** → «Створити демо-набір», потім «Запустити» генератор.

**Чи можна без backend?**
Поточна версія працює з реальним сервером. Демо-режим без backend можна додати окремо за бажанням.
